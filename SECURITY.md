# Security policy

Tessera opens image and project files from anywhere on your computer, so bugs
in file parsing matter. If you find a security problem — for example a file that
crashes Tessera in a way that could be exploited, or a way for a project file to
read or write files it shouldn't — please report it privately through
[GitHub's private vulnerability reporting](https://github.com/MrNechev/tessera/security/advisories/new)
instead of opening a public issue.

Only the latest release is supported with security fixes while Tessera is in
alpha.
